# CSE220-Data-Structures-Lab-Assignments
Solutions and reference implementations for CSE220 Data Structures lab assignments. 
## A Note to Fellow Students

Yes, you can definitely copy and paste these solutions.

But before you do, ask yourself whether you actually understand what the code is doing. Simply copying and submitting a solution might save a few minutes today, but it won't help when you're sitting in a lab exam, midterm, or final and need to write the code on your own.

Try to understand the logic, trace the execution, and ideally reimplement the solution yourself. Your future self will thank you for it. I know I did!
